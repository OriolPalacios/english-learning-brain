# Future ChatGPT scheduled activity prompts

This skill never creates or edits scheduled activities. These prompts are templates the learner can use later in ChatGPT's built-in scheduling interface.

## Optional reading check-in at a privately configured time

```text
Run my English Learning Brain nightly reading check-in for today. Use my privately configured Supabase project, learner slug, timezone, and reading workflow. Ask what I read, request a 3-6 sentence summary in English and the words or phrases I marked, correct me, score the fixed dimensions, and save the reading session, vocabulary, and reusable errors. Do not start the five-item review unless I ask.
```

## Evaluation activity on selected days

```text
Run my English Learning Brain evaluation flow. Use my privately configured Supabase project and learner slug. If the activity configuration says review, generate exactly the deterministic five-item daily plan and administer it one item at a time. If it says exam, generate a 10-item mixed formal assessment. Record every answer, score, confidence, correction, error pattern, and resulting memory state. Do not randomize item selection.
```

The learner chooses days, time, and timezone privately. Do not assume a cadence or publish the schedule.
